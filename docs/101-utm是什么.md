# UTM 是什么

UTM 是贴在链接末尾的几个参数，用来告诉统计工具：这次访问从哪来。页面内容不会因为这些参数改变。

一条完整的例子：

```text
https://example.com/offer?utm_source=facebook&utm_medium=cpc&utm_campaign=spring
```

`?` 后面才是参数。多个参数用 `&` 连起来。

## 五个常用参数

| 参数 | 填什么 | 例子 |
|---|---|---|
| `utm_source` | 从哪个平台来 | `facebook`、`tiktok`、`newsletter` |
| `utm_medium` | 什么类型的流量 | `cpc`、`social`、`email` |
| `utm_campaign` | 这一次活动叫什么 | `spring_2026q1` |
| `utm_term` | 搜索词或定向标签，可空 | `running_shoes` |
| `utm_content` | 同一活动里区分素材，可空 | `video_a` |

还有一个少见的 `utm_id`，用来跟内部工单对齐，可空。

## 三条写错就会拆报表的规矩

1. **全小写。** `Facebook` 和 `facebook` 会被算成两个来源。
2. **不要空格。** 用下划线：`spring_sale`，不要 `spring sale`。
3. **source 是平台，medium 是类型。** 不要两个都填 `facebook`。

## 原链接里已经有参数时

如果落地页地址本来就是 `https://example.com/p?id=3`，再拼 UTM 时要接在后面，变成 `?id=3&utm_source=facebook`。不要再写一个 `?`，也不要留着旧的 `utm_source` 不删——旧的和新的叠在一起，报表会对不上。

`#` 后面的片段要留在整段链接的最后。

## 和点击编号不是一回事

`fbclid`、`ttclid`、`gclid` 是广告平台自己加上的点击编号，不是 UTM。两种都要留着。切语言、短链跳转时，把 `?` 后面的整段带过去，不要只跳一个写死的地址。
