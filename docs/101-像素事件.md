# 像素事件，常见的就这几个

像素是广告平台给的一小段脚本，装在页面上，用来告诉平台：有人看了、有人留了资料、有人下了单。不装，平台只能看见点击，看不见之后发生了什么。

三个平台名字不同，意思差不多。

| 你想记的事 | Meta | TikTok | GA4 |
|---|---|---|---|
| 打开页面 | `PageView` | `PageView` | `page_view` |
| 点了咨询 | `Contact` | `Contact` | `generate_lead` |
| 提交了表单 | `Lead` | `SubmitForm` | `generate_lead` |
| 开始填单 | `InitiateCheckout` | `InitiateCheckout` | `begin_checkout` |
| 订单提交成功 | `Purchase` | `CompletePayment` | `purchase` |

大小写不能随便改。Meta 的 `Purchase` 写成 `purchase` 就是另一件事。

## 四个天天出错的地方

1. **同一段基础脚本贴了两遍。** 一次访问会被记成两次。
2. **转化事件写在页面一打开就发。** `Lead` 和 `Purchase` 只能在人真的提交之后发。放在页头，等于每个访客都算转化。
3. **下单事件没有金额和货币。** `value` 用数字，`currency` 用三位字母，例如 `USD`。不要写 `$49` 这种带符号的字符串。
4. **点了外跳立刻把页面关了。** 先发事件，等一两百毫秒再跳走，否则手机浏览器会把还没发出去的请求掐掉。

## 同一次动作不要记两次

人双击提交、刷新感谢页，都可能再发一次。给这一次动作一个固定编号（常叫 `event_id`）。平台在短时间里看到同一个事件名加同一个编号，只记一次。

编号不要用每次都变的随机数。有订单号就用订单号。没有订单号，就用「页面 + 动作 + 这个访客 + 一个短时间桶」，这样连点两下不会变成两单。

## 点击编号要留着

从广告点进来，地址上常有 `fbclid`、`ttclid` 或 `gclid`。这是平台用来把这次点击和后面的转化对上的。短链、语言切换、二次跳转，都要把这段查询参数带上。丢了，像素还在，也对不上那条广告。
