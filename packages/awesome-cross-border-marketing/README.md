## Landing page builders / 落地页与建站

- [Unbounce](https://unbounce.com/) — Drag-and-drop landing page builder with A/B testing and conversion tools. One of the established names.
- [Instapage](https://instapage.com/) — Landing page platform focused on personalization and ad-to-page matching.
- [Leadpages](https://leadpages.com/) — Simple landing pages and lead capture for small teams.
- [Carrd](https://carrd.co/) — Lightweight one-page sites; good for quick tests and simple offers.
- [Webflow](https://webflow.com/) — Visual web design with full HTML/CSS control. Steeper learning curve, higher ceiling.
- [Framer](https://www.framer.com/) — Design-first site builder with strong motion and responsive controls.
- [Dorik](https://dorik.com/) — No-code website and landing page builder with a template library.
- [Swipe Pages](https://swipepages.com/) — Fast mobile-first landing pages built for paid traffic.
- [Elementor](https://elementor.com/) — WordPress page builder; pairs with any WP host.
- [Google Sites](https://sites.google.com/) — Free, minimal; fine for internal or throwaway pages, not for conversion.
- [爱普落地页 / IpCloak Builder](https://builder.ipcloak.ai/) — No-code landing pages for cross-border ads: templates, visual editing, 69 languages, pixels, COD, PWA. *(maintained by us)*
- [WordPress](https://wordpress.org/) — Self-hosted CMS; the base layer for many landing page stacks.
- [Shopify](https://www.shopify.com/) — Storefront platform; use it when the offer is a full catalog, not a single page.

## Templates & design references / 模板与设计参考

- [ThemeForest](https://themeforest.net/) — Large marketplace of website and landing page themes.
- [Envato Elements](https://elements.envato.com/) — Subscription library of templates, fonts, and stock assets.
- [Creative Market](https://creativemarket.com/) — Fonts, graphics, and template bundles from independent designers.
- [Landingfolio](https://www.landingfolio.com/) — Curated landing page examples and section inspiration.
- [SaaS Landing Page](https://saaslandingpage.com/) — Gallery of SaaS landing pages, filterable by industry and style.
- [PageFlows](https://pageflows.com/) — Recorded user flows from real products; useful for onboarding and checkout patterns.
- [Mobbin](https://mobbin.com/) — Mobile and web UI pattern library from shipped products.
- [Canva](https://www.canva.com/) — Quick ad creatives and social images; not a landing page tool.
- [Figma](https://www.figma.com/) — Design and handoff; the default for teams with a designer.
- [落地页超市 / Culolo](https://culolo.online/) — 291 ready-made landing pages with live demo sites and a demo backend for each. *(maintained by us)*

## Link routing & short links / 分流与短链

- [Bitly](https://bitly.com/) — The default short link service; simple analytics and QR codes.
- [Dub](https://dub.co/) — Link management with conversion tracking; developer-friendly API.
- [Short.io](https://short.io/) — Branded short links with team access and retargeting integrations.
- [Rebrandly](https://www.rebrandly.com/) — Custom-domain short links with click analytics.
- [分流短链 / IpCloak Link](https://link.ipcloak.ai/) — Route one link to multiple agents by weight, with per-recipient attribution. *(maintained by us)*
- [Cloudflare Workers](https://workers.cloudflare.com/) — Roll your own router if you need full control; more engineering time.

- [WhatsApp Business](https://business.whatsapp.com/) — Official business app and API entry point.
- [WATI](https://www.wati.io/) — WhatsApp team inbox, automation, and broadcast for SMBs.

- [Intercom](https://www.intercom.com/) — Support and lifecycle messaging for product-led teams.
- [出海狸 SCRM](https://scrm.chuhaili.ai/) — Multi-account inbox and lead attribution for teams running several social accounts. *(maintained by us)*

## Pixels, analytics & attribution / 像素与分析

- [Google Analytics 4](https://analytics.google.com/) — Free web analytics; the baseline for most ad accounts.
- [Meta Pixel docs](https://developers.facebook.com/docs/meta-pixel/) — Official Pixel setup and event reference.
- [Google Tag Assistant](https://tagassistant.google.com/) — Verify Google tags and events on a page.
- [Microsoft Clarity](https://clarity.microsoft.com/) — Free session recordings and heatmaps.
- [Hotjar](https://www.hotjar.com/) — Heatmaps, recordings, and feedback widgets.
- [Plausible](https://plausible.io/) — Privacy-friendly, lightweight analytics.
- [Umami](https://umami.is/) — Open-source, self-hostable analytics.
- [PostHog](https://posthog.com/) — Product analytics with funnels, recordings, and experiments.
- [Matomo](https://matomo.org/) — Open-source analytics you can host yourself.

## Localization / 多语言与本地化

- [Weglot](https://www.weglot.com/) — Website translation layer with automatic language switching.
- [Lokalise](https://lokalise.com/) — Translation management for product and marketing copy.
- [Crowdin](https://crowdin.com/) — Localization platform with community and team workflows.
- [Phrase](https://phrase.com/) — Enterprise localization suite.
- [DeepL](https://www.deepl.com/) — Machine translation; good first pass, always human-review the checkout and legal copy.

## Open-source building blocks / 开源基建

- [Next.js](https://nextjs.org/) — React framework for app-like pages.
- [Tailwind CSS](https://tailwindcss.com/) — Utility CSS; fast to build consistent pages.
- [GitHub Pages](https://pages.github.com/) — Free static hosting for docs and content sites (not for commercial landing pages).
- [Cloudflare Pages](https://pages.cloudflare.com/) — Static hosting with a global CDN and custom domains.
