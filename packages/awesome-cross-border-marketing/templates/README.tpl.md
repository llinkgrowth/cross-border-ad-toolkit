## Contributing

1. 一个 PR 只加/改一个条目；格式：`- [Name](https://example.com/) — one neutral sentence.`
2. 必须是你真的用过或认真评估过的工具；**不收付费收录、不写 affiliate link、不写贬低同行的描述**。
3. 失效链接直接开 issue，带截图和 HTTP 状态。
4. 与出海投放无关的通用开发工具不收；已经有更好条目的重复项不收。
